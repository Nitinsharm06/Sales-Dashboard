# 📊 Sales Performance Dashboard – Excel

## 📌 Overview

An interactive **Sales Performance Dashboard** created in Microsoft Excel to analyze business performance and generate actionable insights from sales data. The dashboard provides a clear overview of sales, profit, orders, quantity sold, and profit margin.

## 🎯 Key Features

- 📈 Monthly Sales & Profit Analysis
- 🌍 Sales Performance by Region
- 🏷️ Category & Sub-Category Sales Analysis
- 👤 Top Salesperson Performance
- 📊 KPI Cards for key business metrics
- 🎛️ Interactive Filters/Slicers
- 📉 Professional Data Visualizations

## 🛠️ Tools & Skills

- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers & Interactive Filters
- Data Cleaning & Analysis
- Data Visualization
- Dashboard Design
- Business Intelligence

## 📊 KPIs

- **Total Orders:** 1,000

## 🎯 Objective

The objective of this project is to transform raw sales data into an interactive and professional dashboard that helps users monitor performance, identify trends, compare business segments, and make data-driven decisions.
